# Security Policy

This is a proprietary client project shown publicly for portfolio purposes (see [LICENSE](LICENSE)) - it isn't accepting outside contributions, but real security reports are still welcome.

## Reporting a Vulnerability

If you find a security issue (e.g. a way to access data you shouldn't, bypass authentication, or otherwise compromise the live site), please report it privately rather than opening a public issue:

- Email: doanchetoidriz@gmail.com

Please include enough detail to reproduce the issue. We'll acknowledge reports as soon as possible and keep you updated as it's addressed.
