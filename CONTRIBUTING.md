# Contributing

This is a proprietary client project (see [LICENSE](LICENSE)) shown publicly as a portfolio piece — it isn't open to outside pull requests.

That said, if you spot a real bug or have a suggestion, feel free to open an issue describing it. Security issues should go through [SECURITY.md](SECURITY.md) instead of a public issue.

## Local setup

See the [README](README.md#getting-started) for how to get the backend and frontend running locally.

## Before opening an issue

- Check it isn't already covered by an existing issue.
- Include steps to reproduce, what you expected, and what actually happened.
